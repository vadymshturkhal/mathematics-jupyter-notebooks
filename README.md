## 🚀 Open in Google Colab (Recommended for Quick Start)

You can run these notebooks directly in **Google Colab** without installing anything locally.

### Option 1: Open a Notebook Manually

1. Navigate to a notebook file on GitHub.
2. Copy the full URL from your browser.
3. Go to: https://colab.research.google.com
4. Select **File → Open notebook**
5. Choose the **GitHub** tab.
6. Paste the notebook URL and click **Open**.
7. Ignore first two "watermark" cells.
